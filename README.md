# ESN Poland Finances app

This repository contains the **ESN Poland Finances app** developed for the [ESN Poland Federation](https://esn.pl) by [Szymon Cichy](https://github.com/szycic) for financial management. It builds upon the cloud architecture, application structure, and UI foundation originally created by [Matteo Carbone](https://matteocarbone.com) for the [ESN Assembly app](https://github.com/uatisdeproblem/esn-assembly) created for the [Erasmus Student Network](https://esn.org).
